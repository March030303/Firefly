## 运行流程
### app

main.js（入口）
  └─ new Vue({ render: h => h(App), router })
        │
        ▼
App.vue  ← 项目的「根组件」
  │
  └─ <router-view />   ← 这个槽位会根据当前 URL 动态塞组件
        │
        ├─ URL 是 /Login  →  渲染 Login.vue
        ├─ URL 是 /nextLogin  →  渲染 nextLogin.vue
        ├─ URL 是 /HomePage  →  渲染 HomePage.vue（它自己还有一层 <router-view> 渲染 PageRight 等子页面）
        └─ 路由守卫 beforeEach 会做跳转拦截

APP.vue是通过路由展示组件的（routerview)，其实并没有用到Login标签在template


APP--->Login（goto方法）--->nextLogin 

### nextLogin

#### 布局 1-54
login-container (全屏容器)
  ├── el-card (登录卡片，毛玻璃效果)
  │     ├── card-header (品牌 Logo + 标题)
  │     └── el-form (登录表单)
  │           ├── 用户名输入框
  │           ├── 密码输入框
  │           ├── 记住我（复选框）
  │           └── 登录按钮（带 loading）
  └── bg-vivus (背景 SVG 动画层，z-index:1，在卡片下方)
 #### 登录逻辑
 handleLogin()
│
├─ ① 空值校验（手动判断，因为没调用 validate）
│     └─ username 或 password 为空 → $message.error → return
│
├─ ② 发起 POST 请求  /api/admin/login
│     body: { username, password }
│
├─ ③ 请求成功 (res)
│     ├─ res.data.code == 1  ← 后端约定：1 = 成功
│     │   │
│     │   ├─ 存 token / id / userName / role / passwordChangeRequired / adminUser
│     │   │   （全部存到 localStorage，注意：token 没用 httpOnly cookie，安全性一般）
│     │   │
│     │   ├─ 「记住我」处理
│     │   │   ├─ ✅ 勾选 → localStorage.setItem("rememberedAdmin", username)
│     │   │   └─ ❌ 没勾 → localStorage.removeItem("rememberedAdmin")
│     │   │
│     │   ├─ 🔀 分支 A：passwordChangeRequired == 1
│     │   │   └─ 强制跳 /change-password（修改初始密码）
│     │   │
│     │   └─ 🔀 分支 B：正常登录
│     │       ├─ localStorage.setItem("menuactive", "/HomePage/PageRight")
│     │       └─ 跳 /HomePage/PageRight（主页面右侧区）
│     │
│     └─ res.data.code != 1 → $message.error(res.data.msg || "登录失败")
│
└─ ④ 请求失败 (catch)
      └─ 取错误消息的优先级：err.response.data.msg > err.response.data > "登录失败..."
