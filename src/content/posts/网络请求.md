# 前置知识

前端向后端发送请求，拿取数据。所以先用Express（基于nodejs的web开发框架）

1、下载express
```
npm i express
```

2、在js文件中使用express
```
1、引入express

const express = require('express');

2、创建应用对象

const app = express();

```

3、启动express
```
node ???.js
```
