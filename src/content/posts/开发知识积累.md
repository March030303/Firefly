# 前后端联调

```Plain
启动后端 Debug
→ 1、启动管理端或小程序端
→ 2、使用自己的账号登录
→ 3、打开一个列表/搜索页面
→ 4、在 Network 找到请求
→ 5、在后端找到 Controller
→ 6、Controller 命中断点
→ 7、单步进入 Service
→ 8、找到 Mapper/MyBatis XML
→ 9、查看返回的 DTO/VO
→ 10、放行请求并确认页面结果
```
34：也就是在前端/管理端交互一下，f12/网络/xhr的请求报文就会有类似admin/stall/page之类的东西
5：双击shift可以查找
