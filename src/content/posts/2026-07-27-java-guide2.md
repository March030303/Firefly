# <center>封装
**封装**：就是用类设计对象处理某一个事物的数据时，应该把要处理的数据，以及处理这些数据的方法，设计到一个对象中去。要做到==合理暴露，合理隐藏==

没封装的例子：
```java
public class Student{
public double score;
public void printPass(){
    System.out.println(score>=60?"成绩及格":"成绩不及格");
    }
}
```
这段代码让score是公开的，导致可以随便修改score，不符合封装合理隐藏的思想，应当改为private score，并在方法中实现修改score的值

在==方法==中修改score的值，而非==成员变量==中

封装好后的代码：
```java
public class Student{
private double score;
public void setScore(double score){
if(score >= 0 && score <= 100)    
this.score=score; //在方法中修改score的值，并且保证安全性（必在0~100）
else
System.out.println（"数据非法~"）;
    }
public double getScore(){
return score;
    }

public void printPass(){
System.out.println(score>=60?"成绩及格":"成绩不及格");
子
    }
}
```
还要注意set方法和构造器的区别在于：构造器实在new的时候就传参进去了，set则是为了后续动态修改score的值。

# <center>继承
**什么是继承**：继承就是用extends关键字，让一个类和另一个类建立起一种父子关系。
·
**继承后有啥特点**：子类可以继承交类非私有的成员。

**继承后对象能访问哪些成员**：子类对象能访问父类非私有的成员；带继承关系的类，java会用==子类和父类，这多张设计图==来一起创建类的对象。对象能直接访问什么成员，是由子交类这多张设计图共同决定的，这==多张设计图对外暴露了什么成员，对象就可以访问什么成员。==

**单继承**：一个类只能继承一个父类，不能继承多个父类，所有没有父类的类都继承Object类

# <center>多态
## 多态的前提
有继承/实现关系；存在父类引用子类对象（上转型）；存在方法重写，分为==对象多态和行为多态==
## 对象多态and行为多态
```java
People p1 = new Student();//上转型（粗的绳子给小气球）
p1.run();

People p2 = new Teacher();//当然啦，这里People是父类，而且都重写了run方法
p2.run();
```
人（父类）可以是老师也可以是学生，这就是==对象多态==
都是人的行为，但是在不同的对象下表现出不同的特征，这就是==行为多态==

==小补充== 多态不是变量的多态，也就是说如果你父类和两个子类都有String name，但在Test里输出p.name的name也是父类的（这时候不涉及多态，当然就是编译和运行都看左边了）
## 编译看左边，运行看右边
```java
People p1 = new Student();//上转型（粗的绳子给小气球）
```
编译看左边：编译时看左边People p1，知道要在People类里拿设计图（看到People类有run方法了）
运行看右边：运行时看右边new Student()，虽然说编译时看左边People类有run方法编译成功，但实际运行时看的是右边子类重写的方法

## 多态的好处与弊端
```java
public class Test {
public static void main(string[]args){


/好处1：可以实现解耦合，右边对象可以随时切换，后续业务随机改变
People pl=new student();
 pl.run();


/／好处2：可以使用父类类型的变量作为形参，可以接收一切子类对象。 
Student s = new student();
go(s);
Teacher t = new Teacher();
go(t);
public static void go(People p){
        }
    }
}
```

好处1：如果哪天需求变了，比如从学生改成老师，那么只需要People pl=new student()改成People pl=new teacher(); 就可以实现解耦合

好处2：如果是public static void go(Student s)而不是public static void go(People p)，那就不能传Teacher作为参数了

弊端：多态不能调用子类的独有功能（编译时看左边，左边没有，所以编译不通过）
>什么叫独有功能？也就是子类没重写的、自己独有的

怎么解决这个弊端：用==强制类型转换（下转型）==
