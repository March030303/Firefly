# 链表

链表具有两个域：数据域（data）和指针域（下一个结点的指针next）

数据结构：
```
typedef struct LNode{
int data;
node *next
}LNode,*Linkedlist
```

## 初始化
单链表分为：带头结点和不带头结点，具体是看Head在哪个位置
首先要对Head有一定的认识：它可以是头指针
![](https://cdn.jsdelivr.net/gh/March030303/Picgo@main/img/20260916140712808.png)

有头结点：
```
	Status Init(Linklist *L){          //声明，要传入二级指针

    *L = (Linklist)malloc(sizeof(Node));//解引用，拿到一级指针，开辟空间

    (*L)->next = NULL;

        return OK;

    }
    
    
   main里面：Linklist L =Null;Init(&L) 
```
## 插入

### 尾插

先初始化一个链表：
```
int main(){

Linklist Head = NULL;
   Linklist temp1=(Linklist)malloc(sizeof(Node));

   Linklist temp2=(Linklist)malloc(sizeof(Node));

   Linklist temp3=(Linklist)malloc(sizeof(Node));

    temp1->data=10;

    temp2->data=20;

    temp3->data=30;

    temp1->next=temp2;

    temp2->next=temp3;

    temp3->next=NULL;

    Head=temp1;
    
    return 0;

}
```

此时创建一个新结点：
```
//创建结点

    Linklist temp=(Linklist)malloc(sizeof(Node));

    temp->data=40;

    temp->next=NULL;
```

![](https://cdn.jsdelivr.net/gh/March030303/Picgo@main/img/20260916145628072.png)



遍历到原来链表的最后一个结点
```
 Linklist current = Head;

    while(current->next!=NULL){

        current=current->next;

    }
```
![](https://cdn.jsdelivr.net/gh/March030303/Picgo@main/img/20260916150353321.png)




最后再连起来，让原来最后一个结点的next放temp
```
    current->next=temp;
```
